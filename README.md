# Pizzaria d'lima

Single Page Application estática da pizzaria **d'lima**, com abas de navegação para:

- Quem somos
- Onde estamos
- Relatos de clientes
- Quem já passou por aqui

## Rodando localmente

Basta abrir o arquivo `index.html` no navegador.

## Publicando no GitHub Pages

1. Faça push deste repositório para o GitHub.
2. Em **Settings > Pages**, selecione a branch principal e a pasta `/ (root)`.
3. Salve e aguarde a URL ser gerada.

Como o projeto é HTML/CSS/JS puro, ele funciona diretamente no GitHub Pages.
